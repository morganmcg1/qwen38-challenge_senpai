### Effect size versus the advisor's band

The advisor expected −8 % to −14 % at the cell. I measured −20.209 %, which
exceeds the band. The explanation is that `t55` does not merely parallelise the
second row block, it *deletes* it. `<T,5,3>` maps to `[3,2]` and `<T,5,5>` gives
`TAIL = M % IPG = 0`, so the route becomes a single `[5]` group. The saved work
is a whole second x-group load, not a scheduling overlap. `m5_rbx`, which keeps
two blocks and only runs them in parallel, lands at −13.431 %, inside the band.
That contrast is the direct evidence for the mechanism.

This predicts over-performance wherever a cheap tail block is deleted and no
gain where there is no tail. M=9 currently ships `<T,9,5>`, which is `{5,4}`, so
it would over-perform if routed the same way. M=8 ships `<T,8,4>` = `{4,4}` with
no tail, so it should show nothing. I did not test either; see follow-ups.

## Conclusion

- **What happened and why:** routing M=5 to a single NA=5 group removes the
  second row block entirely. The M=5 QMV cell gets 20.209 % ± 0.165 % cheaper,
  and a real 512-token decode gets 1.0453 % ± 0.071 % cheaper per token once
  prefill is removed, at t = −14.67, with exact tokens and a closed row ledger.
- **Evidence for or against the mechanism:** four independent lines agree.
  The `m5_rbx` contrast separates "delete the block" from "parallelise the
  block" and attributes 6.778 % of the 20.209 % to deletion alone. The
  bandwidth model shows the shipped route exceeding the stream peak, which is
  only possible with a partly cache-served second pass. The two instruments
  agree within 2σ. The binary certificate shows `__text` identical and
  `__cstring` different, so nothing but the kernel source string changed.
- **Prompt or M5 transfer risk:** moderate, and it favours the candidate. This
  host ran an M=5 share of 0.047906, while the ranked shares are 24.1 % at M=5
  and 33.4 % at M=6, so the local session under-weights M=5 by about 2.04x
  against ranked. The measured cell effect transfers directly, but the leg
  effect measured here is a *floor* for the ranked leg, not a ceiling. Against
  that, the whole measurement is one public fixture on an M4 Pro, and the ranked
  box is an M5 whose QMV cell timings I cannot reproduce locally.
- **Value, using the advisor's pricer:** `t55` alone is worth about −0.639 % of
  ranked QMV against a deficit of 0.5366 %, which needs −0.646 %. It is a hair
  short on its own, and clears comfortably when composed: `t55` with `t6` prices
  at −3.40 % ranked QMV, −2.808 % candidate leg, and +1.942 % published score
  with sd 2.57.
- **Smallest useful next action:** route M=9 the same way. It ships `<T,9,5>` =
  `{5,4}`, which is the same delete-the-tail shape at a width that carries far
  more ranked weight than M=5, and the M=9 lane-perturb control already fired,
  so the route is reachable. That is one character in each twin again.
- **Recommendation: compose later.** The mechanism is real, the evidence is
  reproducible, and the diff is two characters with zero byte growth. I would
